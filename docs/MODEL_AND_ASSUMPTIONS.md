# Модель и допущения

## Временное разрешение
- Шаг расчёта — 1 час (8760 точек в годовом сценарии).
- Профили нагрузки и ветра детерминированы, без сценарного ветвления.

## Баланс мощности
Для каждого часа выполняется равенство:

\[ \text{load} = P_{\text{hydro}} + P_{\text{wind}} + P_{\text{diesel}} + P_{\text{batt,dis}} - P_{\text{batt,ch}} - P_{\text{curtail}} \]

Ограничения:
- Заряд/разряд АКБ ограничены \(P_{\max,charge}\) и \(P_{\max,discharge}\).
- SOC ограничен диапазоном \([SOC_{min}, SOC_{max}]\).
- Мощность ВИЭ и дизеля ограничена их номиналами и минимумами загрузки (для ДГУ используется `pmin` или 40% номинала).

## Модель аккумулятора
Переменные:
- \(E\) — энергия в кВт·ч;
- \(P_{ch}\), \(P_{dis}\) — запрошенная мощность заряда/разряда, кВт;
- \(\eta_{ch}\), \(\eta_{dis}\) — КПД заряда и разряда (по умолчанию \(\sqrt{\eta_{rt}}\) при заданном круговом КПД `efficiency`).

Правила:
- Одновременный заряд и разряд запрещены: остаётся только доминирующее направление.
- Обновление SOC за шаг \(\Delta t\):
\[ E_{t+1} = \mathrm{clip}\big(E_t + P_{ch}\,\eta_{ch}\,\Delta t - \frac{P_{dis}}{\eta_{dis}}\,\Delta t,\ E_{min},\ E_{max}\big) \]
- Начальный SOC берётся из переданного значения или из середины диапазона, метка `soc_start_source` фиксирует источник (`initial` или перенос между днями).

## Диагностика баланса энергии
Функции `compute_charge_discharge` и `compute_battery_energy_balance` анализируют расписание на предмет непротиворечия SOC:
- `total_charge_kwh = sum(P_charge * eta_charge * dt)`;
- `total_discharge_kwh = sum(P_discharge / eta_discharge * dt)`;
- `delta_soc_kwh = total_charge_kwh - total_discharge_kwh`;
- `energy_balance_residual_kwh = (soc_end - soc_start) - delta_soc_kwh`.

Если модуль остатка превышает `max(abs_tol, rel_tol * |delta_soc|)`, в `warnings` добавляется сообщение о несоответствии баланса. Также проверяется отсутствие пересечения заряда и разряда по шагам.

## Дополнительные допущения
- Система островная: внешняя сеть не рассматривается.
- Коммутационные/динамические ограничения генераторов не моделируются, кроме `pmin` и `pmax` для ДГУ и ограничений по мощностям/границам SOC для АКБ.
