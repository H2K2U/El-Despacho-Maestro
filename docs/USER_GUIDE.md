# Руководство пользователя

## Обзор интерфейса
Главное окно разделено на области:
- **Загрузка данных**: кнопки для загрузки профиля нагрузки (8760 часов) и опциональных данных ветра.
- **Каталоги оборудования**: списки и диалоги для добавления дизельных станций, МГЭС, ВЭУ и АКБ.
- **Управление оптимизацией**: выбор алгоритма (жадный, Differential Evolution, Grey Wolf), запуск и отображение прогресса.
- **Вкладки визуализации**: покрытие нагрузки, профиль SOC АКБ, выбранное оборудование, сводка оптимизации, экономический анализ.

## Базовый сценарий
1. **Загрузите профиль нагрузки** (8760 часов, один час = один шаг).
2. **Загрузите данные ветра** (при наличии) в тех же временных отметках.
3. **Добавьте оборудование** из каталогов: дизельные станции, МГЭС, ВЭУ и АКБ. Можно использовать файлы из `data/`.
4. **Выберите алгоритм оптимизации** и нажмите запуск.
5. **Изучите результаты** во вкладках: покрытие нагрузки, профиль SOC, состав оборудования, сводка по целевой функции и экономике.

## Графики
- **Покрытие нагрузки**: столбчатое представление, где положительные столбцы показывают вклад МГЭС, ветра, дизеля и разряда АКБ, а отрицательные значения отображают заряд АКБ и вынужденное снижение генерации.
- **Профиль SOC АКБ**: линия SOC по часам с горизонтальными линиями min/max, столбцы зарядной и разрядной мощности по шагам.

## Таблицы и метаданные
Справа от графиков выводятся ключевые показатели АКБ:
- `soc_start_kwh`, `soc_end_kwh` — начальный и конечный SOC (кВт·ч).
- `total_charge_kwh`, `total_discharge_kwh` — накопленный заряд/разряд на стороне SOC.
- `delta_soc_kwh` — изменение SOC за период.
- `efficiency_used` — применённые КПД заряда/разряда.
- `warnings` — список предупреждений (например, нарушения баланса энергии).
- `soc_start_source` — источник начального SOC (`initial` или перенос с предыдущего дня).

## Типовой годовой прогон
1. Импортируйте годовой профиль нагрузки и ветра (8760 точек).
2. Подготовьте каталоги оборудования (пример в `data/`).
3. Запустите Differential Evolution или Grey Wolf Optimizer для подбора числа ВЭУ/АКБ, затем изучите вкладки графиков и таблицы SOC.
