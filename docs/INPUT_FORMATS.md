# Форматы входных данных

Ниже приведены ожидаемые форматы файлов, исходя из кода загрузчиков (`core/data_loader.py`) и моделей (`core/models.py`). Везде предполагается шаг 1 час и единицы измерения в киловаттах/кВт·ч.

## Профиль нагрузки
- Формат: CSV или XLSX.
- Обязательные столбцы: `Время`, `Потребление`.
- Время конвертируется через `pandas.to_datetime` (поддерживаются `dd.mm.yyyy HH:MM` и варианты с секундами).
- После загрузки столбец `Потребление` переименовывается в `load` и используется как активная мощность нагрузки в кВт.
- Индекс устанавливается по столбцу времени. Длина ряда для годового расчёта — 8760 строк.

| Column name | Тип / единицы | Описание |
|-------------|----------------|----------|
| `Время` | datetime | Метка часа (1-часовой шаг). |
| `Потребление` | float, кВт | Спрос на активную мощность. |

## Данные ветра
- Формат: CSV или XLSX.
- Обязательные столбцы: `Время`, `Скорость` (м/с).
- После загрузки столбец `Скорость` переименовывается в `wind_speed`; индекс — по времени.
- Данные должны быть синхронизированы по шагам с профилем нагрузки.

| Column name | Тип / единицы | Описание |
|-------------|----------------|----------|
| `Время` | datetime | Метка часа. |
| `Скорость` | float, м/с | Скорость ветра на высоте измерения. |

## Каталог дизельных установок
- Формат: Excel с кривой расхода топлива.
- Модель `DieselUnit` ожидает:

| Column name | Тип / единицы | Описание |
|-------------|----------------|----------|
| `load` | float, кВт | Нагрузка, при которой измерен расход топлива. |
| `consumption` | float, л/ч или кг/ч | Расход топлива при указанной нагрузке. |

Дополнительные атрибуты задаются при создании объекта:

| Поле | Единицы | Описание |
|------|---------|----------|
| `name` | строка | Имя ДЭУ. |
| `nominal_power` | кВт | Номинальная мощность. |
| `efficiency` | доля | КПД. |
| `pmin` (опционально) | кВт | Минимальная нагрузка, по умолчанию 40% номинала. |

Каталог может содержать несколько ДЭУ, сгруппированных в `DieselPlant`.

## Малые ГЭС
- Формат: Excel/CSV с гидрографом или кривая, считываемая функцией `load_hydro_graph_excel`.
- Допустимы два варианта: (1) две строки — месяцы 1–12 и соответствующие расходы; (2) два столбца `Месяц` и `Среднемесячный расход`.
- Параметры модели:

| Поле | Единицы | Описание |
|------|---------|----------|
| `name` | строка | Имя станции. |
| `nominal_power` | кВт | Номинальная мощность. |
| `efficiency` | доля | КПД турбины. |
| `head` | м | Напор, по умолчанию 50 м. |
| `hydro_graph` | м³/с | Словарь {месяц → расход}, используется для расчёта доступной мощности. |

## Ветроустановки
- Формат: Excel с кривой мощности по скоростям ветра (колонки 0–25 м/с).
- Обязательные поля для каждой строки:

| Column name | Тип / единицы | Описание |
|-------------|----------------|----------|
| `Turbine` | строка | Название модели. |
| `Rated_Power_kW` | кВт | Номинальная мощность. |
| `Hub_Height_m` | м | Высота втулки. |
| `Cut_in_Wind_Speed_m/s` | м/с | Скорость включения (опционально, дефолт 3). |
| `Rated_Wind_Speed_m/s` | м/с | Номинальная скорость (опционально, дефолт 15). |
| `Cut_out_Wind_Speed_m/s` | м/с | Скорость отключения (опционально, дефолт 25). |
| `0` … `25` | кВт | Колонки со скоростями (0–25 м/с) и мощностью в каждой точке; используются для построения `power_curve`. |

## Аккумуляторные батареи
- Формат: Excel (лист `АКБ`).

| Column name | Тип / единицы | Описание |
|-------------|----------------|----------|
| `Наименование` | строка | Название модели. |
| `E_nom_kWh` | кВт·ч | Номинальная ёмкость. |
| `P_charge_max_kW` | кВт | Максимальная мощность заряда. |
| `P_discharge_max_kW` | кВт | Максимальная мощность разряда. |
| `eta_charge` | доля | КПД заряда (также используется как КПД разряда, если не задан отдельно). |
| `SOC_min` | доля | Минимальный SOC (0–1) или значение в долях, если <1. |
| `SOC_max` | доля | Максимальный SOC (0–1) или значение в долях, если <1. |

### Допущения и обработка отсутствующих данных
- При отсутствии `eta_charge`/`eta_discharge` используется разбиение круглосуточного КПД `efficiency` на \(\sqrt{\eta}\) для заряда и разряда.
- SOC-границы интерпретируются как доли от ёмкости, если значения ≤1; при больших значениях принимаются как кВт·ч.
- Начальный SOC по умолчанию устанавливается в середину диапазона (`(soc_min + soc_max)/2`).
