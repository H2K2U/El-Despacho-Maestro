# Валидация и тесты

Тесты сосредоточены на непрерывности SOC и корректности энергетического баланса АКБ (`tests/test_battery_state.py`).

## Проверяемые инварианты
- **Баланс SOC**: изменение SOC за период совпадает с интегралом заряда/разряда с учётом КПД, остаток должен быть в допуске.
- **Отсутствие одновременного заряда и разряда** на одном шаге.
- **Минимизация неудовлетворённой нагрузки**: в тестовых сценариях суммарный `unserved` ≈ 0.

## Покрытые сценарии
- **Одноаккумуляторный пример на 48 часов**: постоянная нагрузка, одна ДЭС и АКБ — проверяется непрерывность SOC между сутками и точность баланса (`_assert_continuity`).
- **Укороченные прогоны DE и GWO**: малые популяции и итерации, чтобы проверить, что даже при сокращённом горизонте сохраняется баланс SOC и нулевой дефицит.
- **Порог предупреждений по балансу**: искусственное нарушение баланса разряда должно вызвать предупреждение `energy balance mismatch`.

## Как запустить тесты
```bash
pytest
```
Или точечно для SOC:
```bash
pytest tests/test_battery_state.py
```
Успешный запуск без предупреждений подтверждает корректность расчёта SOC и баланса энергии в расписании.
