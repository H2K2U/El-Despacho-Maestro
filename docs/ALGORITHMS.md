# Алгоритмы оптимизации

Алгоритмы реализованы в `core/algorithms/`. Общая целевая функция минимизирует топливо, неудовлетворённую нагрузку и штрафы:
- базовый критерий — суммарный расход топлива и перекачка через расписание `diesel_total`;
- штраф за неудовлетворённую нагрузку (`unserved`), dump/curtailment, число часов работы и запусков ДГУ, одновременный заряд/разряд АКБ;
- при необходимости добавляется прокси на CAPEX ВЭУ/АКБ.

## Жадный алгоритм
Файл `core/algorithms/greedy.py`.
- Пошаговая диспетчеризация по часам: сначала МГЭС, затем ВЭУ, затем подбор комбинации ДГУ с учётом `pmin`, остаток закрывается АКБ.
- Используются прогнозные окна для оценки дефицита и выбора SOC-таргета на шаге.
- Плюсы: быстрый, устойчив к неполным данным. Минусы: не гарантирует глобальный оптимум.

## Differential Evolution
Файл `core/algorithms/de.py`.
- Вектор решения кодирует индексы выбранной ВЭУ/АКБ и их количества (ограничены по пиковой нагрузке через `_compute_limits`).
- Параметры по умолчанию: `population_size=25`, `generations=40`, `mutation_factor=0.7`, `crossover_rate=0.9`, `seed=42`.
- Используется двухуровневая оценка: FAST окна по 168 часов (пики по сумме и по максимуму) для быстрой фильтрации и регулярная FULL оценка на всём горизонте. Лучшие кандидаты проходят локальный поиск вокруг наилучшей точки FAST.
- Оценка кандидата выполняет жадное расписание и вычисляет фитнес с учётом топлива, неудовлетворённой нагрузки, dump, числа часов/запусков ДГУ и пересечения заряд/разряд.

## Grey Wolf Optimizer
Файл `core/algorithms/wolf.py`.
- Модель стаи: позиции волков соответствуют тем же параметрам (индекс/число ВЭУ и АКБ). Альфа/бета/дельта задают направление обновления популяции.
- Ограничения по количеству оборудования рассчитываются из пикового спроса (`_compute_limits`).
- Каждый кандидат оценивается жадным расписанием; фитнес включает топливо, dump, число часов/запусков и возможный CAPEX-прокси для ВЭУ/АКБ.
- Итерации заканчиваются по числу шагов (`iterations`, например 30) или достижении лучшего значения; лучшая особь возвращается как оптимальное решение.
