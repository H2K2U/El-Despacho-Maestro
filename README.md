# El Despacho Maestro

Оптимизатор автономных энергосистем и гибридных микрогридов (дизель, малые ГЭС, ветроустановки, АКБ) с графическим интерфейсом на PySide6. GUI позволяет загрузить часовые профили (8760 часов), выбрать оборудование из каталогов, запустить оптимизацию разными алгоритмами и визуализировать покрытие нагрузки, профиль SOC и экономику.

## Возможности
- Импорт профилей нагрузки и ветра на 8760 часов.
- Работа с каталогами оборудования: дизельные станции, малые ГЭС, ветроустановки, аккумуляторы.
- Алгоритмы оптимизации: жадный диспетчер, Differential Evolution, Grey Wolf Optimizer.
- Визуализация покрытия нагрузки, профиля SOC, экономической оценки.
- Диагностика баланса энергии АКБ (непрерывность SOC, предупреждения о несоответствии баланса).

## Быстрый старт
1. **Требования:** Python 3.10+.
2. **Создайте виртуальное окружение и установите зависимости:**
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
   pip install -r requirements.txt
   ```
3. **Запуск GUI:**
   ```bash
   python main.py
   ```
4. **Запуск тестов:**
   ```bash
   pytest
   ```
   Для быстрой проверки SOC можно запустить целевой тест:
   ```bash
   pytest tests/test_battery_state.py
   ```
